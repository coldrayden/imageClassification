**Image Classifier**

I took on this learning exercise to build an intuition on why Convolutional Neural Networks (CNNs) work well on image data.

Some concepts I learned and practiced include:

1. Neurons and Layers
2. Convolution operations
3. Kernels/filters
4. Activation functions (ReLU, Sigmoid, Softmax). Understanding when to use what. Sigmoid or Softmax used on the Output layer. Sigmoid used for binary choices, Softmax used for multiple choices with probabilities summing to 1
5. Forward Propagation
6. Loss functions, Gradient Descent, and Backprop. Understanding the idea behind minimizing loss functions
7. Overfitting and Regularization
8. Transfer learning
